# WMForge Website

Responsive website for WMForge — practical SAP Warehouse Management learning resources.

## Files
- `index.html` — page content and navigation
- `styles.css` — responsive visual design and animations
- `script.js` — mobile navigation, scroll progress, reveal effects, and back-to-top control
- `assets/wmforge-logo.png` — WMForge logo
- `assets/wmforge-banner.png` — WMForge poster/banner

## Test locally
Open this folder in VS Code and run `index.html` with the Live Server extension.

## Publish with GitHub Pages
Upload/commit the files and the complete `assets` folder to the root of the repository. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/(root)`, then save.

## Before launch
- Replace the resource enquiry links with actual download links when the free PPTs are ready.
- Keep premium files out of this public repository. Public repository files can be accessed by anyone.
- The premium collection and training buttons currently open prefilled emails; this website does not process payments or protect paid downloads.
- Review the site content and contact details before launch.
