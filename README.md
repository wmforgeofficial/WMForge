# WMForge Website

A responsive, animated landing website for WMForge — SAP Warehouse Management.

## Files
- `index.html` — website content and sections
- `styles.css` — visual design, responsive layout, and animations
- `script.js` — mobile navigation, scroll reveal, scroll progress, and back-to-top interaction
- `assets/` — WMForge logo and banner

## Publish with GitHub Pages
1. Upload all files and the `assets` folder to the root of the repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Before launch
- Confirm the free PPT files and add their links/buttons to the resource section.
- Keep paid files out of this public repository. Public repository files are accessible to everyone.
- The premium collection and training buttons currently open prefilled emails to `wmforgeofficial@gmail.com`.
- Add actual YouTube video IDs or individual video links as the library grows.
- Review all copy, privacy information, terms, and contact details before announcing the site.

## Important
This starter site does not process payments or protect premium downloads. Payment requests are handled manually by email; verify payments before sending files privately. Do not add passwords, API keys, customer data, or payment details to this repository.
